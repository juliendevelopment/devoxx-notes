Room 8 · Conference · 13:50-14:40

## Summary

The talk critiques dogmatic use of Clean and Hexagonal Architecture, arguing that unnecessary abstraction can hurt code clarity and maintainability. Using Java examples, it explores trade-offs and decision metrics—coupling, cohesion, and distance—to help choose architecture based on context rather than universal "best practices."
