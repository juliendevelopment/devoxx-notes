## Summary

AI-enabled migration of a banking mainframe to the cloud required a shift from "vibe coding" to "harness engineering." The talk shows how to control AI-generated code in regulated environments through spec-driven development, evolutionary pipelines, and continuous validation, balancing agility, safety, and changing security rules.
