# 11:50 Rise of Agent enablement

[The Rise of Agent Enablement: Coding Agents Don't Scale Themselves. Neither Do Your Teams.](https://m.devoxx.com/events/dvbe26/talks/21671/the-rise-of-agent-enablement-coding-agents-don-t-scale-themselves-neither-do-your-teams) by [Patrick Debois](https://m.devoxx.com/events/dvbe26/speaker/21519/patrick-debois)
Room 6 · Conference · 11:50-12:40

## Summary

The talk argues that "dark factory" readiness is organizational, not technical. Using Conway's Law, it outlines four enablement layers: agent, team, platform, and organization. It targets engineering leaders scaling agentic coding beyond tools, focusing on roles, rituals, infrastructure, ROI, and knowledge capture.
